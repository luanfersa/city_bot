Política de privacidad

Última actualización: 1 de octubre de 2026

CITY INVESTMENT utiliza WhatsApp para brindar atención, responder consultas y gestionar comunicaciones con sus clientes. AGENTECH proporciona soporte técnico para la operación de esta integración.

Datos recopilados

Podemos procesar el número de teléfono, nombre de perfil, mensajes, archivos enviados, datos de la conversación y registros técnicos necesarios para prestar el servicio.

Uso de la información

La información se utiliza para responder consultas, prestar soporte, mantener el historial de atención, mejorar el servicio y proteger la seguridad de la plataforma.

Proveedores

La prestación del servicio puede involucrar a Meta Platforms, WhatsApp, AGENTECH y proveedores tecnológicos necesarios para almacenar y procesar las comunicaciones. No vendemos información personal.

Conservación y seguridad

Los datos se conservan durante el tiempo necesario para prestar el servicio y cumplir obligaciones legales. Aplicamos medidas razonables para impedir accesos no autorizados.

Acceso y eliminación de datos

Para solicitar acceso, corrección o eliminación de información, envíe el texto ELIMINAR MIS DATOS mediante el mismo canal de WhatsApp. Podremos verificar la identidad antes de procesar la solicitud.

Cambios

Esta política puede actualizarse. La versión vigente estará publicada en esta misma dirección.
